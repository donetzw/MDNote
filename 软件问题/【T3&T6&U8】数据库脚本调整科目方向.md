> 0表示贷方，1表示借方，以下脚本是用于上下级科目方向不一致，统一调整方向

```sql
update code  set bproperty = '0' where ccode like '2171%'
update code  set bproperty = '0' where ccode like '3141%'
update code  set bproperty = '1' where ccode like '1131%'
update code  set bproperty = '1' where ccode like '1431%'
update code  set bproperty = '0' where ccode like '1502%'
```
