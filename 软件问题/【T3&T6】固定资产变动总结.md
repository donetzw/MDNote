|   变动类型    | 变动制单  |   变动影响   |
| :-------: | :---: | :------: |
| 原值增加/原值减少 | 需要制单  | 下月变动月折旧额 |
|  累计折旧调整   | 需要制单  | 不影响月折旧额  |
|  使用状况变动   | 不需要制单 | 变动后不计提折旧 |
|  折旧方法调整   | 不需要制单 | 本月变动月折旧额 |
|   部门变动    | 不需要制单 | 不影响月折旧额  |
|  使用年限调整   | 不需要制单 | 本月变动月折旧额 |
|   净残值调整   | 不需要制单 | 下月变动月折旧额 |
|  资产类别调整   | 不需要制单 | 不影响月折旧额  |

#### 总结
所有变动内容都是当月生效，涉及到月折旧额的变动，除了折旧方法、使用年限是当月开始变动折旧额，其它都是下月开始生效
